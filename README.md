# 环球文化贴纸地图

一张学语言的世界贴纸地图：真实的地方、地图上的人（NPC）、在那里发生的事，以及由此产生的对话。

- 首页 `index.html`：世界贴纸地图（贴图模式 / 徽章散开模式可切换）
- `scenes/italy-bar.html`：意大利咖啡吧样板场景
- `scenes/refuse-client.html`：沟通场景样板“拒绝甲方的新要求”

说明：
- 视频在本网站里用 YouTube 播放器直接播放。
- AI 练习、伙伴（关注、聊天、邀请码）等功能需要自己的后端，目前在本网站上会显示“需要在 Claude 里打开”。
- NPC 人物、示例对话都是虚构的；照片来自维基共享资源（署名见各卡片）。
